# Stylized wildlife sources and modifications

Only free assets are used. No commercial pack has been purchased.

The existing [Rabbit](https://opengameart.org/content/rabbit-0) (CDmir/TinyWorlds) and [Boar](https://opengameart.org/content/boar) (Teh_Bucket) are genuine free skinned source models. Their source locomotion stays in use with painted materials. Rabbit uses source jump for the slower hop and Running for fast locomotion; boar's source walking cycle is accelerated for pursuit, and idle/death are authored. See ../forest/ATTRIBUTION.md.

[Crocodile](https://opengameart.org/content/crocodile) by Micket is a CC0 mesh already included. Its weighted rig and five clips were authored in the previous integration. Both crocodiles now use the complete skinned mesh directly; the giant is a scaled variant. The original download did not include those animations.

Materials are simplified and smooth shaded for a consistent stylized game. Models face -Z and feet align to ground in Godot. Supplemental motion is keyframed animation, not motion capture. No Fortnite or Uncharted assets are included.
