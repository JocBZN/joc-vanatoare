# Animal assets — CC0

These sources were published under CC0 (selected from the offered licenses where multiple licenses exist).
Original source archives are retained in `source/`; Godot imports skip that directory.
The project uses transformed glTF / native Godot scenes and the original texture artwork.

| Species | Author / source | Source content and project changes |
| --- | --- | --- |
| Rabbit | CDmir / Čestmír Dammer, TinyWorlds — [Rabbit](https://opengameart.org/content/rabbit-0) | Textured FBX and skeleton animations; converted, normalized and mapped to idle/run/death |
| Deer | CDmir / Čestmír Dammer — [Deer Female](https://opengameart.org/content/deer-female) | Textured FBX; idle/run/death clips combined; explicit diffuse maps; see `../deer/ATTRIBUTION.md` |
| Wild boar | Teh_Bucket — [Boar](https://opengameart.org/content/boar) | Packed texture, skeleton, walk and attack; mirror modifier applied; idle/death added in Godot |
| Wolf | tomek — [3D wolf animation for game](https://opengameart.org/content/3d-wolf-animation-for-game) | Female textured model with idle/walk/run/attack/death; unused second mesh removed |
| Brown bear | STKRudy85 — [White bear low poly](https://opengameart.org/content/white-bear-low-poly) | Original textured polar bear was unrigged; brown material tint, quadruped skeleton and five animation cycles added |

License: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
The models are a low-poly prototype foundation, not final high-resolution wildlife artwork.
The bear tint multiplies the existing texture in the material; its original white source remains intact.
