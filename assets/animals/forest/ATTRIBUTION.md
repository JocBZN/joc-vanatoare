# Forest animal assets — current sources and historical credits

These sources were published under CC0 (selected from the offered licenses where multiple licenses exist). Original source archives are retained in `source/`; Godot imports skip that directory.

The current deer and wolf use Quaternius's skinned models and authored animations. Their current credits are in [stylized/ATTRIBUTION.md](../stylized/ATTRIBUTION.md), with downloadable source URLs, license and hashes in [deer_wolf_sources.json](../stylized/deer_wolf_sources.json). The older deer/wolf sources below remain historical credits for retained files.

| Species | Status | Author / source | Source content and project changes |
| --- | --- | --- | --- |
| Rabbit | Current | CDmir / Čestmír Dammer, TinyWorlds — [Rabbit](https://opengameart.org/content/rabbit-0) | Textured FBX and skeleton animations; normalized, with source Jump for the slower hop and Running for fast movement; painted materials |
| Deer | Historical | CDmir / Čestmír Dammer — [Deer Female](https://opengameart.org/content/deer-female) | Previous textured FBX, idle/run/death clips and diffuse maps; files remain credited in [deer/ATTRIBUTION.md](../deer/ATTRIBUTION.md). Current Quaternius model: [stylized credits](../stylized/ATTRIBUTION.md) |
| Wild boar | Current | Teh_Bucket — [Boar](https://opengameart.org/content/boar) | Source textured skeleton, walk and attack; mirror modifier applied; idle/death authored in Godot; painted materials |
| Wolf | Historical | tomek — [3D wolf animation for game](https://opengameart.org/content/3d-wolf-animation-for-game) | Previous female textured model and idle/walk/run/attack/death clips; unused second mesh removed. Current Quaternius model: [stylized credits](../stylized/ATTRIBUTION.md) |
| Brown bear | Current mesh source, new project rig | STKRudy85 — [White bear low poly](https://opengameart.org/content/white-bear-low-poly) | Original polar-bear mesh was unrigged. Current bear has a new weighted 26-bone quadruped rig and five project-authored actions, plus painted materials; the old polar-bear atlas is not used by the current model |
